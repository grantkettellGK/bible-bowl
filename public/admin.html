Upload a JSON file with a book’s text. Re-uploading a book with the same name replaces it. After uploading, assign it to students from the Students tab.

Drop a .json file here or

Expected JSON format 
{
  "book": "Acts",
  "translation": "NKJV",
  "chapters": [
    {
      "chapter": 1,
      "verses": [
        { "verse": 1, "text": "The former account I made, O Theophilus..." },
        { "verse": 2, "text": "..." }
      ]
    }
  ]
}

Also accepted: verses as a plain array of strings, or chapters as an object map like {"1": {"1": "text..."}}. A file may also contain an array of several books.
